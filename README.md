# 🎬 MovieProject

A movie browsing application developed using **C# and .NET MAUI** as part of my software development studies.

## 📱 About

MovieProject allows users to browse a collection of movies and interact with them through a mobile-friendly interface.

The project was created to practise application development using .NET MAUI, while working with data, user interaction, navigation, and persistent storage.

## ✨ Features

* 🎬 Browse movies
* 🔎 Search and filter movies
* ❤️ Add and remove favourite movies
* 👤 User login
* 💾 Persistent storage
* ⚙️ Application settings
* 🌙 Dark mode
* 📱 Mobile-friendly interface

## 🛠️ Technologies

* **C#**
* **.NET MAUI**
* **XAML**
* **JSON**
* **Local storage**
* **MVVM**

## 📚 What I Learned

Through this project I gained experience with:

* Building applications using .NET MAUI
* Applying the **MVVM architecture**
* Managing application state
* Working with JSON data
* Implementing persistent local storage
* Creating reusable UI components
* Handling navigation between pages
* Designing an application for different screen sizes
